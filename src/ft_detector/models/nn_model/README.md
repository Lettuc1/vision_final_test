# 装甲板神经网络素材

- `armor.onnx`：装甲板四角点模型
- `sample_1.jpg`、`sample_2.jpg`：从 `red_1&3.bag` 的 `/hk_camera/image_raw/compressed` 提取的原始画面，可用于开发测试，完整测试请使用素材包中的 Bag

## 模型协议

| 项目 | 内容 |
| --- | --- |
| 输入 | `images`，`float32`，`NCHW [1, 3, 480, 640]` |
| 输出 | `output0`，`float32`，`[1, 21, 6300]`，最后一维为候选 |
| 输入图像 | BGR 原图等比缩放至 640×480 画布，居中补边，补边值 124；转 RGB，像素除以 255 |
| 输出 0–3 | 颜色分数，索引 0=蓝、1=红、2=熄灭；索引 3 为其他类，可忽略 |
| 输出 4–12 | 装甲板编号分数，依次为哨兵、1、2、3、4、5、前哨站、基地、基地 |
| 输出 13–20 | 四个角点的 `(x,y)`，单位是模型输入画布的像素；模型顺序为左上、左下、右下、右上 |

输出分数可直接用于阈值筛选，无须再做 sigmoid。四角点应按缩放与补边参数映射回原图，再按左上、右上、右下、左下排序供 PnP 使用。若要去重，可用四点外接框做 NMS。
